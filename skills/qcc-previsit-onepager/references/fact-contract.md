# 事实卡片与证据合同

## 卡片结构

| 字段 | 规则 |
| --- | --- |
| fact_id | 从 F-001 连续编号 |
| entity | 必须等于锚定法律主体 |
| category | 工商、股权、人员、经营、知识产权、风险、触达 |
| statement | MCP 返回可直接支持的事实 |
| source_capability | 内部保留实际企查查能力；最终报告不展示工具名 |
| source_tier | L1、L2、L3、L4 或 L5 |
| retrieved_at | 本次取得时间 |
| source_time | 数据日期、所属期或当前快照 |
| status | obtained、empty、partial、failed、conflict |
| scope_note | 金额、角色、状态、窗口、是否只有计数等边界 |

## 证据层级

- L1：经审计财报等高质量财务证据，通常仅上市主体可得
- L2：工商、许可、验收、年报、公告、招投标、司法、知识产权等公开行为证据
- L3：官网自述、媒体报道、关系线索，只作佐证
- L4：用户提供但尚未核验的信息
- L5：现场回答和访谈信息
- 模型推断不是事实层级，不计为证据

## 取得状态

- obtained：足以支持陈述
- empty：调用成功但返回零条，只描述本次查询结果
- partial：只取得计数、摘要或部分字段
- failed：工具未成功，不能写成零条
- conflict：不同返回冲突，必须并列待确认

## 引用与独立性

1. 每条核心事实显示 fact_id。
2. AI 研判和假设必须引用至少一个 fact_id。
3. 同一公告的多篇转载合并为一项证据。
4. 官网自述或媒体报道不能单独支撑经营状态。
5. 无事实支持的内容只能进入未知或现场必问。
6. 风险事实保留类型、件数、当事人角色、案号、金额原值、日期和状态。

## 假设卡片

每个假设单独记录：

- hypothesis_id
- priority：P0/P1/P2
- statement
- supports：fact_id 列表
- objections：fact_id 或“反证检索未发现公开记录”
- unknowns
- falsification_search：若假设为假应看到什么、实际查了什么
- confidence：低/中/中高；公开数据阶段禁止高

未知栏整体进入现场问题。未执行 falsification_search 时置信度只能为低。

## 覆盖声明

- 已覆盖：成功取得事实或风险扫描的维度
- 部分覆盖：只有计数、摘要或部分字段
- 未覆盖：服务未接入、未调用、调用失败、无权限或 Provider 限流
- 未获得财务佐证：非上市或 L1 财务能力不可得时必须明确

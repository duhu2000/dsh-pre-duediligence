# 报告衍生文件与交付申请 三期

已保存的 completed/partial 版本可转换为 PDF、DOCX，不重新调用 MCP、不变更报告内容或版本号。当前任务材料输出和历史详情提供生成及下载入口，会话可调用 `previsit_report_export` 和 `previsit_report_files`。

## 文件格式与存储

使用 docx 生成 OOXML ZIP、PDFKit 生成 PDF，不把 HTML 改后缀冒充 Word/PDF。当前为保真文本版：正文和 Markdown 标记原样保留，非 HTML 富排版复刻，不载入远程图片、链接资源或脚本。文件含主体、版本、任务标识；采用 Letter 纵向页面和自动换行。

PDF 需管理员在启动 DSH 前设置 `DSH_PREVISIT_PDF_FONT` 为具有中文覆盖的独立 TTF/OTF 文件绝对路径。字体不随 npm 包分发，使用者须确认授权；未配置或无法读取时导出失败，无成功文件记录。须以实际部署字体进行中文及特殊字符视觉验收。

Word 默认指定 Arial Unicode MS，可用 `DSH_PREVISIT_DOCX_FONT` 更换为部署环境已安装的中文字体家族；DOCX 不嵌入字体，打开端须有该字体或有效替代字体。当前导出不是富排版PDF/Word模板引擎。

衍生文件由独立 Host storageDomain `previsit_report_files_v1` 保存，不向原报告任务写回运行状态。按任务、正文哈希、格式、渲染器版本去重；保存源正文 SHA256、输出文件 SHA256、字节数和生成时间。文件内容上限20MB，下载校验哈希；重启可恢复。转换失败不创建成功记录。现有HTML下载保持不变。

## 交付边界

`previsit_delivery_request` 仅登记用户明确要求的目标和文件，状态固定为 awaiting-configuration（待配置，尚未上传）。禁止自动发起网络请求，也不能以申请记录冒充上传回执。目标只接受无用户名/密码、无查询参数的HTTPS URL，避免将令牌存入任务。

本轮没有目标系统配置，尚未实现真实上传适配器。接入前必须明确目的系统、允许路径、认证来源、权限和用户授权，并实现发送中/成功/失败/结果未知、外部回执及幂等重试。敏感报告不发送到模型自行猜测的网盘、CRM或邮件地址。

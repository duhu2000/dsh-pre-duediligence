# DSH-UX-001 v1.1.2 采纳与验收记录

日期：2026-09-07。业务插件：`dsh-pre-duediligence@0.1.7`。规范源：[共享交互规范 v1.1.2](../../../../AI-设计/DSH智能体开发交互规范方案.md)，视觉参考：[企查查蓝交互 Mockup（原文件名 v1.1.0，内容 v1.1.2）](../../../../AI-设计/DSH智能体_企查查蓝_UI_Mockup_v1.1.0.html)。

## 页面与品牌映射

| 规范区域 | 本插件实现 | 隔离边界 |
| --- | --- | --- |
| 左侧入口 | 菜单名固定为“访前尽调”，使用 Mockup 的线性建筑 SVG；只创建并进入专属 Session | 位于工作区列表前；不调用 `openTab`，初始页右栏关闭；隐藏 Better Sidebar 标签菜单项 |
| 中央首页 | 标题“访前尽调一页纸智能体”，同排建筑 LOGO，独立说明行 | 只在插件创建的空白 Session 可逆改写；卸载时恢复宿主标题、图标和预览标识 |
| 原生输入区 | Composer 下方五项快捷菜单；左上角“提示词生成” | 不替换输入框、模型、权限和原生发送按钮 |
| 提示词向导 | 对象 → 角色场景 → 范围深度 → 确认输出 | Portal 到 body；回填不发送；已有草稿显式选择替换、追加或取消 |
| 右侧工作台 | 当前任务 / 任务历史；招投标式五步等宽导航（上图标、下短标题、无描述）；由输入框下方快捷按钮打开和恢复 | Better Sidebar 是唯一权威工作台；关闭不取消会话任务；不另设会话头打开入口；窄屏菜单不横向越界 |
| 下载材料 | 自包含 HTML 一页纸报告 | 只使用已捕获的当前 Session 报告，不跨 Session 合并 |

## 菜单与阶段映射

| 首页菜单 | 工作台视图 |
| --- | --- |
| 企业核验 | 对象与目标 |
| 经营画像 | 资料采集 |
| 风险核查 | 证据核验 |
| 访前材料 | 材料输出 |
| 任务历史 | 任务历史 |

五步导航为：对象与目标 → 范围确认 → 资料采集 → 证据核验 → 材料输出。导航采用招投标右侧菜单的单行等宽分栏、上图标下短标题、细分隔线样式；选中项使用浅蓝底、蓝字和底部蓝线，菜单内不显示第二行描述。导航选择仅表示用户正在查看的页面，不表示阶段已经完成。

## 状态映射

| UI 状态 | 真实依据 |
| --- | --- |
| 待设定 | 当前 Session 未认领访前任务 |
| 等待确认 / 继续 | 已有任务但未运行，或 Agent 已停止且尚未捕获符合契约的完整报告 |
| 正在尽调 | 当前 Session 快照 `running === true` |
| 报告已生成 | 当前 Session 已捕获含核心研判及现场必问/覆盖说明的报告 |
| 需要处理 | 当前 Session 有 Agent 错误 |

工作台不以“运行停止”代替“报告完成”，也不以菜单点击或阶段切换伪造执行状态。

## Token 与组件

浅色品牌 / 动作色为 `#128BED / #0875D1`，深色为 `#55ADFF / #82C3FF`；表头、背景、文字、边框、成功和复核色均按 v1.1.2 候选表实现。小号白字主按钮使用动作色，深色模式动作按钮使用深色文字。所有变量限定在 `.qcc*` 自有节点，不覆盖全局 `:root`。

## DSH 兼容范围与例外

- 依赖 DSH `>=0.1.1-rc.2` 与 `dsh-better-sidebar@0.17.1` 的公开能力。
- 首页标题因宿主暂未提供会话级 headline slot，采用已知 `[data-phase="hero"]` / headline DOM 的局部、可逆兼容桥；未知结构下保留宿主原样。
- 本轮不新增跨会话持久化历史库；“任务历史”只展示当前 Session 已认领任务，完整历史以 DSH 原生会话为准。
- 尚未在所有未来 DSH 版本和所有第三方插件组合中完成实机视觉验收，兼容范围不外推。

## 实机验收清单

1. 普通会话不出现访前标题、菜单、提示词触发器或工作台恢复入口。
2. 从“访前尽调”进入后，只显示专属初始会话，右侧工作台关闭；菜单与首页显示同一建筑 LOGO，首页名称和说明行居中。
3. 浅色、深色及 390px 窄屏下，无横向页面溢出；移动输入字号不低于 16px。
4. 向导正文可滚动、头尾固定；Tab 不越出弹窗，Escape 关闭并恢复焦点。
5. 输入框已有文字时验证替换、追加、取消三条路径；回填后不自动发送。
6. 点击输入框下方五项业务按钮后才打开对应工作台视图；关闭不取消任务，再点同组按钮可重新打开。
7. 右侧五阶段菜单为等宽分栏、上图标下短标题且无第二行描述；选中项有浅蓝底、蓝字和底部蓝线，390px 窄屏不横向越界。
8. Agent 停止但无完整报告时仍显示“等待确认 / 继续”；完整报告出现后才显示“报告已生成”并允许下载。

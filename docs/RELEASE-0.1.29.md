# 0.1.29 · 商机图片与多企业尽调计划

合入产品 fix11 的 11 份补丁，支持在工作台导入 PNG、JPEG、WebP 或 PDF，也可在访前专属会话的原生输入框拖入、粘贴。识别需要已连接支持本机 `file_path` 的文档解析 MCP；文件最大 8 MiB，凭证绑定来源 Session、15 分钟有效。识别失败可在有效期内重试，同一凭证不会重复登记计划。

从图片、文字或表格登记企业名单后，可在计划卡或会话中确认企业、深度、角色、场合、重点关注、输出框架及重点段落。每家企业建立独立 Host 任务，逐家保存报告，并进入现有 Profile 历史。完成上一家后工作台跟随下一家；恢复待确认计划时，旧报告不会抢占计划卡。图片和计划提交保留原生输入框草稿。

保留 0.1.28 的工作台单次展开、不限次固定路由查询、主体确认和八段报告核验门。段落选择表示重点展开，未选择段落简写。详细兼容取舍见 [合并记录](MERGE-PRODUCT-FIX11.md)。

验证包含 202 项测试、类型检查、构建，以及桌面/390px、深色/浅色四组隔离浏览器回归。数据均为合成数据；真实文档解析和企查查 Provider 联调仍需配置对应服务后验收。

发布遵循现有流程：发布提交的 main CI 通过后创建注释标签 `v0.1.29`，由 GitHub OIDC Trusted Publishing 发布，并回读 npm 版本、integrity 和 provenance。不修改旧标签或复用旧版本。

```sh
dsh plugin --profile web add dsh-pre-duediligence@0.1.29
```

升级前停止对应 DSH Profile，安装后完整重启。需要回滚时安装原先记录的精确版本并使用升级前任务目录备份。

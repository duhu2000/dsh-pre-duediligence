# 0.1.32 — 可读采集摘要与过程证据

- 采集结果按维度组织摘要卡片，默认关键字段，折叠来源与已保存样本；股权、知识产权、资质等全部已查询维度可回看。总记录数与实际样本明确区分，不自动推断全量覆盖。
- 新增 previsit_record_analysis：任务内保存核验发现或机会假设，包含支持、反证、未知、下一步及真实 runId/factId。相同 id 追加修订，持久保存、历史回看。支持与反证状态校验引用存在性，不代替人工判断证据是否充分。
- 证据核验页展示明细范围与结构化核验，不再复制采集页完整扫描卡片。假设存在不再视为反证完成。
- 老报告兼容“假设 1（优先）”标题，明确为报告提取、无过程证据，不补造历史时间线。
- 完成及部分完成均保留当前页面；点击“查看报告”才导航。正常运行的阶段跟随保持原逻辑。

记录更新依赖模型在自然阶段调用工具，不保证单次长生成期间持续产出新结论；缺记录时如实提示。已发布任务不可修改，新增内容需继续尽调子任务。

# 双引擎推理框架

## 双轨关系

机会引擎回答“企业正在发生什么、值得现场验证什么”；风险引擎回答“哪些信号会改变拜访优先级、哪些事项需先内部核实”。

风险不是机会假设的反证。两轨分别求真，在行动层合成。进入风险暴露期时风险轨优先。

## 产业定位（先于状态识别，作为整条推理的上下文）

锚定完成后、进入状态识别前，先用 get_company_profile 确定产业定位。它不是一个展示段，而是状态判定和假设生成的输入：同一信号在产业链不同环节含义不同。

三要素（原样引用工具返回字段，字段名以实际暴露为准）：

- 主营产品与业务模式：靠什么赚钱
- 行业分类与产业链环节：上游材料 / 中游制造 / 下游应用 / 服务
- 环节经营与资金特征：该环节典型的资金占用、周期与风险形态

数据边界：仅实际返回字段可引用为来源信息，业务模式、产业链环节的推导必须标“推理说明”；产业链概览标注“企查查产业链概览（数据加工摘要）”，不得当作订单、客户合作或收入的直接证据。上下游具体标杆企业名单为推理综述，非 MCP 事实，须与事实分区。

### 画像扩展与复访可比性

- 工商国标行业（门类/大类/中类/小类）与企查查行业（一级/二级/三级/四级）分列；分类不同不等于异常，不互相补全缺失层级。
- 注册地区不等于实际经营地点，可与联系方式、招聘等来源比对，并保留各自来源与时间。
- 企业规模标签不等于人员规模、参保人数、营收或信用；主营产品不证明订单、产能或客户合作。
- 同一画像工具中的简介、产品、行业、规模不是多条独立行为证据，不能据此通过状态判定门或提高风险等级。
- 空数组、空层级或字段缺失写“本次未返回”；产品空数组可能源于不适用或上游降级，不推断“无主营产品”。
- 复访中旧记录缺字段而新记录有字段，标记“本次首次取得，历史不可比”，不能描述为企业新增产品、规模扩大或行业变更。仅双方存在同口径信息时比较；真实变化仍需日期与行为证据。不得修改已发布报告。

用法：产业定位确定后，机会引擎按“产业链环节 × 经营状态 × 角色”实例化假设，而非只按状态。例：同为“客户导入期”，上游材料企业的机会假设指向下游供应链准入与账期，下游应用企业指向渠道与终端回款。

## 经营状态速查

| 状态 | 主要 L2 公开行为信号 | 判定边界 | 现场自证 |
| --- | --- | --- | --- |
| 产能建设期 | 行政许可、设备采购招标、土地、新设生产子公司、工程岗招聘 | 备案不等于开工，建设规模不证明融资需求 | 项目投入进度与未来 6–12 个月资金计划 |
| 客户导入期 | 认证新增、销售/FAE 招聘、专利软著、首次中标 | 送样不等于定点，定点不等于订单 | 哪些客户已从验证转批量，周期多长 |
| 产能爬坡期 | 竣工/环保验收、招聘转产线岗、参保环比增长 | 先行验收不等于投产，设计产能不等于实际产量 | 当前利用率、良率与月度产量 |
| 订单增长期 | 中标增长、产线招聘放量、参保增长 | 中标可能是框架；应收增长需结合营收 | 新增订单客户、账期和回款周期 |
| 稳定经营期 | 信号平稳、变更少 | “无变化”也要给时间窗 | 未来 12 个月经营重点 |
| 收缩承压期 | 参保下降、分支注销、减资、质押上升、劳动纠纷 | 单一信号不等于收缩，注销可能是整合 | 主动聚焦还是被动收缩 |
| 资本运作期 | 融资、增资、股东变更、上市辅导或公告 | 历史融资不等于当前需求 | 本轮资金用途与账户安排 |
| 风险暴露期 | 失信、被执行、税务异常、冻结等扫描非零 | 风险轨整体优先；红线不当面直问 | 先内部核实再决定是否推进 |

## 状态判定门

进入条件：唯一实体锚定完成，并取得工商照面和至少一类近期行为数据。

退出条件：

- 至少 2 个独立 L2 信号；或
- 1 项行政许可、官方验收等高权威直接证据。

不满足时：

1. 按当前档位补查下一优先级行为工具；
2. 仍不足则写“状态未定”；
3. 降级为清单式简报；
4. 不生成状态驱动的业务假设。

行为信号必须带日期。超过 24 个月只能作为历史沿革。

## 假设与反证门

进入条件：状态置信度至少为“中”。

每个假设必须包括：

- 假设 ID
- P0/P1/P2
- 支持事实
- 反对事实
- 未知
- 反证检索
- 假设置信度

退出条件：每个假设至少执行一项“若为假应该看到什么”的检索。未完成时置信度封顶为低，且不得进入核心研判。

优先级：

- P0：价值高、可当面验证、证据至少为中，进入首屏与必问
- P1：价值高但证据弱，或价值中但证据强，进入报告但不抢占必问名额
- P2：只入完整报告附录

## 证据独立性

| 来源 | 独立性 | 规则 |
| --- | --- | --- |
| 官方登记、许可、验收、裁判文书 | 高 | 各计独立证据 |
| 企业公告、年报、招投标原始公告 | 高 | 各计独立证据 |
| 数据平台结构化聚合 | 中 | 追溯到原始来源后按原始来源计 |
| 企业官网自述、媒体报道 | 中低 | 只作佐证，不能单独判状态 |
| 二次转载 | 低 | 与原始公告合并计 1 |
| 模型推断 | 0 | 不计为证据，只能标推理说明 |

## 置信度

- 低：单一 L2 或仅关系推断
- 中：至少 2 个独立 L2 相互印证
- 中高：L2 组合加 L1 财务佐证，或高权威官方直接证据
- 高：仅在现场验证后使用

状态置信度与假设置信度必须分开。

## 报告进入门

进入条件：机会轨与风险轨均已完成，或已对失败/未接入维度作真实披露。

退出条件：

- 报告八段齐全（产业定位为独立第二段）
- 每个判断带 fact_id
- 必问回指未知栏并带答案分支
- 覆盖度说明已查、未查、失败和证据层级

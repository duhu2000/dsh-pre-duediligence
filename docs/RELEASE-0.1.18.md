# dsh-pre-duediligence 0.1.18

Version: **0.1.18**
Date: **2026-09-12**

## 本次修复

- 修复中文输入法在“拜访客户”输入框确认候选词时，把“苏州”等未完成内容误提交为任务的问题。
- 任务启动时冻结企业与选项快照；Host 启动后以任务检索词为准，确认主体后立即展示完整法律实体名称。
- 报告整理期间保留最后一次真实资料采集或证据核验页面，制品真正生成后才自动切换“材料输出”。
- 仅在真实候选主体状态提示用户选定企业；已确认主体显示实时调用数和报告整理状态。
- 默认选中银行/信贷客户经理、全部六项关注、3分钟速览和一页纸简报；“要见谁”更名为“拜访客户”。

## 验证与边界

- 非安装器测试 21 个文件 / 140 项通过；严格类型检查和构建通过。
- 浅色/深色 × 桌面/窄屏共 4 个真实 Chrome 隔离场景通过，覆盖标签、默认选中态、输入回车隔离和无横向越界。
- 测试使用合成 Host / Provider 记录，未配置生产模型或企查查 OAuth，未消耗真实额度。
- 黄色“待核验”仍表示 Provider 结构不足以确认语义，不会因为报告整理或生成而伪装成绿色完成。

## 升级

```sh
dsh plugin --profile web add dsh-pre-duediligence@0.1.18
```

安装后完整停止并重启对应 DSH Web Profile。Better Sidebar 仍为可选工作台；stable 与 candidate 必须使用 README 列出的成套版本。

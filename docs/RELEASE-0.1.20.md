# dsh-pre-duediligence 0.1.20

Version: **0.1.20**
Date: **2026-09-12**

## 本次修复

- 适配企查查 Provider 的真实中文业务返回。工商、画像、股东、董监高、联系方式、风险扫描等非空成功对象会显示绿色；明确零记录、无权限和失败保持各自语义。
- 风险扫描直接读取生产结构中的 `风险因子扫描 / 明细工具 / 条目数`，数字和数字字符串均可驱动零计数跳过与非零明细下钻。
- “已取得 / 已核查”改为中性的“采集结果 / 核验结果”，完成、待确认、未完成和失败分别计数，避免标题与右侧徽标互相矛盾。
- 风险分级按业务含义着色：明确未发现为绿色，关注项为黄色，红线为红色，信息项为蓝色；绿色旁明确说明其只代表本次公开数据核查结果。

## 验证与边界

- Node 24.18.0 下严格类型检查、22 个测试文件 / 157 项测试、Host/Client 构建及浅色/深色 × 桌面/窄屏 4 个隔离 Chrome 场景通过。
- Provider 契约测试采用真实企查查返回字段的脱敏样本，不包含客户数据、账号或访问令牌。
- 绿色表示本次查询成功且未发现相应公开记录，不代表企业绝对无风险；无权限、未知、未执行和失败不会变绿。
- 生产账号的端到端结果仍取决于 Connector、OAuth、产品权限、Provider 额度与限流。

## 升级

```sh
dsh plugin --profile web add dsh-pre-duediligence@0.1.20
```

安装后完整停止并重启对应 DSH Web Profile。Better Sidebar 仍为可选工作台；stable 与 candidate 必须使用 README 列出的成套版本。

# dsh-pre-duediligence 0.1.17

Version: **0.1.17**
Date: **2026-09-11**

## 本次修复

- 报告制品上架后，Host 任务进入不可回退终态；后续查询和额度耗尽跳过不再把任务改回“正在尽调”。
- 已有报告制品、但被旧版本回写成 `running/finalizing` 的任务会在读取时自愈；缺失完成时间时自动补齐，当前任务和任务历史统一显示“报告已生成”。
- 顶部资料采集/证据核验阶段、四个子步骤和各维度标签共享蓝/绿/黄/红/灰状态体系。
- 已执行且成功或明确无数据的项目显示绿色；已返回但语义待核验的项目显示黄色，不伪造证据完整性。
- 主体锚定以实际 `previsit_confirm_entity` 完成事件驱动，不再因企业搜索返回归类为 `unknown` 而保持灰色。

## 验证与边界

- 自动化覆盖报告终态防回退、旧记录自愈、历史状态收敛、阶段聚合和子项状态色契约。
- 测试使用合成 Host / Provider 记录，未配置生产模型或企查查 OAuth，未消耗真实额度。
- 报告生成表示任务交付完成，不表示所有数据维度全量覆盖；待核验、无权限、未执行和失败仍分开显示。

## 升级

```sh
dsh plugin --profile web add dsh-pre-duediligence@0.1.17
```

安装后完整停止并重启对应 DSH Web Profile。Better Sidebar 仍为可选工作台；stable 与 candidate 必须使用 README 列出的成套版本。

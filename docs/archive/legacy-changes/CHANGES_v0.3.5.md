# v0.3.5 变更：文案去"作战卡"、字号放大、下载兜底、小屏修复

## 1. 流程与文案（克制、四字、不再出现"作战/卡"）
- 四阶段：尽调设定 → 经营研判 → 风险核查 → 尽调报告
- 状态：待设定 / 等待执行 / 正在尽调 / 报告已生成 / 需要处理
- 报告页：标题「尽调报告」，一句说明"不是资料堆砌，只回答四件事：去不去、见谁、聊什么、什么不能碰"
- 按钮：新的尽调 / 下载报告 / 查看完整报告 / 返回会话
- 报告本体改名「访前尽调报告 · 企业名」（Skill、模板、导出文件名同步）；下载文件名「访前尽调报告_企业名.html」

## 2. 工作台字号与对比度
- 全部字号上调约 3px（8→11、9→12、10→13、11→14…），次要文字颜色从三级灰改为二级灰。

## 3. 「下载报告」点击无反应
- 原因：会话快照里取不到正文时按钮是禁用态，点了没反馈。
- 修复：按钮始终可点；快照取不到时改从对话区已渲染的报告 DOM 取（去样式、去控件，套同一报告外壳）；
  两者都取不到时在页脚给出红色提示，不再静默。

## 4. 小屏样式错乱
- 对话输入框旁的「访前尽调」入口在窄屏下逐字竖排：已加 nowrap / flex:none。

## 应用
同前：覆盖 skills/ 与 lib/，Ctrl+C 后重新 dsh web，刷新。验证 version: 0.3.5。

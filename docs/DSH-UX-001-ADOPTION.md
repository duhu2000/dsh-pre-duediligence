# DSH-UX-001 采纳与验收记录

## 0.1.19：工作台输入隔离与核验闭环

日期：2026-09-12。

| 交互要求 | 当前实现 |
| --- | --- |
| 侧栏中文输入不得影响原生会话 | “拜访客户”逐字输入只更新插件 Session Store，不调用宿主 `setDraft`；键盘与 composition 事件继续隔离，仅点击“开始尽调”才一次性提交 |
| 档位不应提前终止核验 | 移除 8 / 18 / 40 次插件硬上限；三档只控制查询优先级、覆盖深度与目标时长 |
| 必查与无需执行都要闭环 | 风险非零项必须实际下钻；零计数逐项记录“无需执行”。关键人员有数据时必须执行董监高风险扫描，无数据时明确跳过 |
| 每一子项有可解释状态色 | `done / no-data / skipped` 绿色，`unknown / no-permission / not-executed` 黄色，失败红色，运行中蓝色；跳过原因随 Host run 同步 |

上述规则延续工作台初始关闭、Session 单例 Tab、企查查蓝品牌和招投标式阶段菜单，不改变宿主容器控制权。

| 交互要求 | 0.1.18 实现 |
| --- | --- |
| 表单输入不得触发宿主发送 | “拜访客户”输入框的 keydown/keyup/composition 事件止于组件；输入法确认候选词不启动任务 |

浅色品牌 / 动作色为 `#128BED / #0875D1`，深色为 `#55ADFF / #82C3FF`；表头、背景、文字、边框、成功和复核色均按 v1.1.3 候选表实现。小号白字主按钮使用动作色，深色模式动作按钮使用深色文字。所有变量限定在 `.qcc*` 自有节点，不覆盖全局 `:root`。

## DSH 兼容范围与例外

- 依赖 DSH `>=0.1.1-rc.2` 与 `dsh-better-sidebar@0.17.1` 的公开能力。
- 首页标题因宿主暂未提供会话级 headline slot，采用已知 `[data-phase="hero"]` / headline DOM 的局部、可逆兼容桥；未知结构下保留宿主原样。
- 本轮不新增跨会话持久化历史库；“任务历史”只展示当前 Session 已认领任务，完整历史以 DSH 原生会话为准。
- 尚未在所有未来 DSH 版本和所有第三方插件组合中完成实机视觉验收，兼容范围不外推。

## 实机验收清单

1. 普通会话不出现访前标题、菜单、提示词触发器或工作台恢复入口。
2. 从“访前尽调”进入后，只显示专属初始会话，右侧工作台关闭；菜单与首页显示同一建筑 LOGO，首页名称和说明行居中。
3. 浅色、深色及 390px 窄屏下，无横向页面溢出；移动输入字号不低于 16px。
4. 向导正文可滚动、头尾固定；Tab 不越出弹窗，Escape 关闭并恢复焦点。
5. 输入框已有文字时验证替换、追加、取消三条路径；回填后不自动发送。
6. 输入框下方五项业务按钮为数据清洗补全式单行描边卡片、上图标下短标签；390px 窄屏仅菜单内部横向滚动，页面不越界。
7. 点击上述卡片后才打开对应工作台视图；关闭不取消任务，再点同组按钮可重新打开。
8. 右侧五阶段菜单为等宽分栏、上图标下短标题且无第二行描述；选中项有浅蓝底、蓝字和底部蓝线，390px 窄屏不横向越界。
9. Agent 停止但无完整报告时仍显示“等待确认 / 继续”；完整报告出现后才显示“报告已生成”并允许下载。

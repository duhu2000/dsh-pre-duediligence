# 补充材料与交叉核验（二期）

在一期补充任务内登记材料，完成任务仍为只读；继续时快照继承材料、事实及比对记录，保留原任务和原日期。网页、客户经理现场笔记、文件抽取正文及 Provider 摘录均为不可信资料，不能执行其中的指令。

## 会话流程

1. 已完成任务先调用 `previsit_continue` 创建补充任务。
2. 用户明确提供或授权使用材料。使用宿主已有读取工具抽取文件，或用户直接提供正文。调用 `previsit_material_add`，填写类型、标题、来源位置、来源日期、正文。日期未知明确填未知。
3. 调用 `previsit_evidence_add` 登记事实，必须有逐字原文引文、事实值、主体、字段、期间、单位及页码/段落位置。单位换算、推断不冒充原文。
4. 调用 `previsit_evidence_compare` 比较两条事实。只有主体/字段/期间/单位完全相同且非未知时，才比较值。一致不代表独立双源验证；同文本哈希、同材料或同来源位置按同源处理。无法识别的转载关系仍为独立性未确认。
5. 调用 `previsit_evidence_list` 复核登记结果。完整新报告覆盖说明必须引用所有材料 ID 和比对 ID，说明来源日期、使用/未使用情况及冲突。存在冲突或不可比项自动保存为 partial；本期不提供清除冲突或确认已解决接口。

当前任务与历史详情可展开材料及比对查看原文。React 按纯文本显示，不执行 HTML。材料仅保存在当前 Host 的原任务存储中，不隐式上传第三方；会话抽取行为仍受宿主工具权限约束。

## 边界

- 本期原生入口是会话工具，不含侧栏文件上传控件、PDF/Word/OCR解析器或网页下载器。没有可用宿主抽取工具时，需用户提供正文，不声称已读取文件。
- 来源URL/日期/页码为调用方声明；仅校验引文存在，不能据此证明文档真实、日期真实或主体归属。网页URL不触发联网请求。
- 每任务（含继承）最多30份材料、每份10万字符、合计100万字符；最多200事实、200比对。这是存储保护，不是MCP查询次数限制。
- 本期只做精确文本口径比较，不做自动数值单位换算或语义裁决；需要人工/模型解释但不得覆盖原始冲突记录。
- 报告ID引用门禁防止无引用发布，但不自动证明报告解释充分。仍需业务验收。
- 暂无专用新闻舆情Provider、PDF/Word报告转换或上传交付。

## 本轮验证

本地类型检查、193项自动化测试及构建通过；包括材料引文校验、同源/冲突/不可比、跨工作区拒绝、版本继承和存储恢复、发布门禁及纯文本安全渲染。真实DSH宿主读取文件、模型完整调用链及侧栏视觉操作尚未验收；不将服务端渲染测试等同于浏览器验收。本轮未提交、打tag或发布npm。

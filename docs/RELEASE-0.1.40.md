# 0.1.40：工商与企业画像字段适配

升级：`dsh plugin --profile web add dsh-pre-duediligence@0.1.40`，重启 DSH 并刷新页面。

- 工商登记显示注册地区与分层国标行业，地区代码在详情中保留。
- 企业画像显示简介、企查查行业、最多 10 项返回产品、规模及数据加工摘要。
- 兼容旧行业文本及缺字段；来源数据不等同分析结论。产品空数组不推断无主营业务。
- 复访对比必须区分首次取得与企业真实变化。旧报告及历史记录不改写，不自动补查。
- 仅适配已有 registration/profile 查询；主体绑定、固定路由、历史隔离、报告终态、实验卡片默认关闭保持不变。
- 新增 portrait 为可选持久化摘要，旧记录继续走原有摘要显示。并非完整工具结果备份：简介/概览各限 1200 字、产品最多 10 项，其他原始信息仍见会话工具结果。
- 本轮使用合成数据测试，不代表真实 DSH 或生产 QCC 返回已联调验收。

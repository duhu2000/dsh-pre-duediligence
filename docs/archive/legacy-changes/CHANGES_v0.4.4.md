# v0.4.4 变更：入口收敛、精简过程

## 1. 入口
- 去掉输入框工具行里的「访前尽调」按钮、左侧边栏底部的「访前尽调」按钮。
- 提示词生成条的标题行右侧加「工作台」按钮，打开右侧工作台。
- 会话头部保留一个「工作台」入口。

## 2. 过程显示：精简 / 完整（会话头部右上角切换，默认精简，记住选择）
精简模式下：
- 一串连续的工具调用只显示最后一行（每一"轮"只留一行），不再一行一个 Tool call 排满屏；
- 已结束的 Think 行隐藏，正在进行的 Think 保留（还能看到"在想什么"）；
- 「上下文注入」行隐藏；
- 只含思考/工具块、没有正文的空步骤隐藏；
- 助手写出来的正文、报告、最终结论完整保留。
切到「完整」即恢复 DSH 原样。实现是纯 CSS（按 DSH 每个会话节点自带的 data-chat-flow-kind 属性），不改 DSH 渲染逻辑。

## 应用
同前：覆盖 skills/ 与 lib/，Ctrl+C 后重新 dsh web，刷新。验证 version: 0.4.4。

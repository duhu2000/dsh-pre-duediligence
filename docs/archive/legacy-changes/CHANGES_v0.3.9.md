# v0.3.9 变更：两边状态同步

## 问题
从设定条或直接在输入框发起尽调后，右侧工作台仍显示"等待设定"、不跟踪进度。
原因：工作台只认自己（旧版面板里的按钮）登记的任务；设定条发出的任务登记在发送前的会话 ID 上，
DSH 首页空白会话在第一次发送时会换成正式会话 ID，登记就对不上；直接按发送键发出的更是没有登记。

## 修复：从会话本身认领任务
工作台和设定条都改为"看会话说话"：
- 会话里最后一条带「访前任务 ID：PV-…」的消息 → 认领为该任务，从那条消息开始计数；
- 没有标记但已出现企查查工具调用（直接在输入框里发的）→ 认领为"会话内发起"，从头跟踪。
不再依赖谁点了哪个按钮；打开任何一个正在跑或跑完的尽调会话，工作台四个阶段都能对上。
设定条在认领到任务后自动折叠，摘要显示"尽调进行中"。

## 应用
同前：覆盖 skills/ 与 lib/，Ctrl+C 后重新 dsh web，刷新。验证 version: 0.3.9。

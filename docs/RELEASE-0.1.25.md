# 0.1.25 · 历史阶段回顾与实时风险事实

- 历史清单隐藏当前任务阶段导航；历史详情提供独立五阶段只读回顾，不改变当前任务，不重新调用 MCP。
- 查询结束时保存有界摘要、经营字段与风险因子计数，随 Host 状态同步到工作台。新增字段向后兼容。
- 资料采集与证据核验均展示即时风险命中。绿色查询完成不代表企业无风险；公开记录命中使用关注色，最终红线分级仍依据报告。
- 移除八张静态经营状态占位卡，展示实际返回的经营摘要、事实及最终研判。
- 最终风险分级展示全部条目，不再仅展示每类第一项。

## 边界

历史回顾展示已保存的阶段结果，不是逐秒事件录像。旧记录未保存的摘要、范围字段明确标注不可用，不猜测、不补调用。扫描命中属于公开记录事实，不自动等同于失信或违法定性。验证使用合成数据与隔离浏览器；生产 DSH/MCP 仍需升级后验收。

## 发布

通过本地检查、浏览器回归及 main CI 后创建注释 tag。GitHub Actions 使用既有 npm Trusted Publishing 自动发布，并核对 registry 与 provenance；不依赖人工重复 npm 登录。

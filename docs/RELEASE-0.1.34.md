# v0.1.34

- 新任务自动展开对象与目标；主体绑定前不进入资料采集。已确认主体先展示范围，再按真实查询进入采集或核验。用户手动浏览后保留当前页，报告完成不强制跳转。
- 完成后的风险摘要区分本次明确未发现、已发现事项与结论未明确；兼容加粗表格级别和明确的红线文字结论，缺省项不自动判零。
- 风险明细与采集覆盖默认展示客观摘要，仅长字段保留折叠。
- 当前报告底部统一下载 PDF（主要）、Word、HTML；PDF/Word 一次点击生成并下载，失败可重试。历史详情使用同一格式入口。
- 移除底部宿主技术提示及过时的管理员字体配置说明。PDF 内置字体保持不变。

更新不会修改已保存报告正文或重跑历史查询。旧报告缺少明确分级时如实显示结论缺口，需继续尽调补充，不以完成状态代替核验。

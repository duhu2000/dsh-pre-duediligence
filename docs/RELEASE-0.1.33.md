# 0.1.33 — 采集与核验职责分离

- 资料采集只显示来源摘要、扫描计数与客观明细；经营研判、假设、分析修订历史全部移至证据核验。
- 核验页不再重复原始查询卡片；风险研判前置，红线独占一行，关注和信息分开展示。未形成结论时不显示“红线0”。
- verification 记录新增可选 riskLevel（红线/关注/信息），必须有支持依据及真实证据引用；不根据计数自动分级。新修订立即更新阶段摘要，发布后优先展示报告结论，保留过程记录。
- “机会假设与现场验证”改为“机会假设与证据验证”；onsite 显示“待客户确认”。缺失信息属于未知，不自动作为反证。
- 无需下钻项目合并显示明确原因，不再出现“缺少摘要”和“0项字段”的大卡片。
- 保留当前阅读页、历史回看及不可覆盖报告版本；旧记录不猜测风险级别。

自动化回归覆盖页面职责、分级引用校验、修订更新、未知状态与跳过项。当前字体打包方案未修改，本次不涉及字体拆包。

# dsh-pre-duediligence 0.1.16

Version: **0.1.16**
Date: **2026-09-11**

## 本次修复

- “提示词生成”移入输入卡片的独立顶部区域，不再与用户会话正文的第一行重叠。
- 识别 DSH 原生嵌套 `message.role`，使直接从原生对话框发送的访前任务能正确认领会话和报告边界。
- 右侧工作台不再等待本地 `PV-*` 任务，会主动发现当前 Session 的 Host `PVT-*` 任务；任务一启动就离开可重复提交的“开始尽调”页。
- 候选主体确认后，范围页立即使用 Host 返回的完整法律实体名；例如“思必驰”更新为“思必驰科技股份有限公司”。
- Host 进入资料采集、证据核验或材料输出时，右侧只在真实阶段变更时自动前进，并按秒更新工具 run 状态；用户手动查看其它页时不被每次轮询强制拉回。

## 验证与边界

- 本地非安装器测试：20 个文件 / 129 项通过；TypeScript 严格检查与 Host/Client 构建通过。
- 浅色/深色 × 1440×900 / 390×700 共 4 个隔离 Chrome 场景通过，新增“触发器不覆盖草稿”与“顶部 48px 预留”断言。
- 本机 Node 25 不在声明支持范围，安装器用例在本地按版本门禁拒绝；发布 CI 在 Node 22.19 / 24 四组支持矩阵中运行全量测试。
- 测试使用合成 Host / Provider 记录，未配置生产模型或企查查 OAuth，未消耗真实额度，不声明真实 Provider 验收通过。

## 升级

```sh
dsh plugin --profile web add dsh-pre-duediligence@0.1.16
```

安装后完整停止并重启对应 DSH Web Profile。Better Sidebar 仍为可选工作台；stable 与 candidate 必须使用 README 列出的成套版本。

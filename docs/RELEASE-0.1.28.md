# 0.1.28 · 任务接纳后自动展开工作台

采用 DSH-UX-001 v1.5.5 / UX-48。菜单进入、输入和提示词回填不展开；原生 `beginSubmission.onRetire` 的 `observed` 接纳事件与直接发送成功，共用单次展开控制器。工作台绑定提交所属 Session，不切换或影响其他 Session。
